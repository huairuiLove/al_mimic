## 目标

把"splits.hdf5 组装"作为正式预处理步骤加回 MIMIC-III 数据流水线（重构时被删除），生成含 `subject_id` 的持久化训练张量产物；并用它修复本地现有 15GB splits.hdf5，使 `validate-data` 能通过。不改动任何现有 loader/audit 契约。

## 背景（已核实）

- 本地中间产物齐全且行序全部对齐（均 10258 行）：`population/population.hdf5`（ID+Diagnoses_LABEL 915 维）、`features/.../IDs.csv`、`features/.../notes.hdf5`（pandas 旧布局，`read_notes` 已支持）、`features/.../Xs.hdf5`（稠密 float32 X+s，gzip，184MB，可避免 sparse 依赖）、`prep/icustays_MV.csv`（含 SUBJECT_ID、FIRST_CAREUNIT、partition=train/val/test，cohort 子集计数 7242/1540/1476 与现有 splits 完全一致）。
- 现有 `fiddle_processed/.../splits.hdf5` 缺 `subject_id`，因此 `audit_split_hdf5` 会拒绝（`data.py:62-69`）。
- git 历史 `af4479f^` 有完整 `scripts/build_splits.py`（组装器）与 `scripts/assemble_yang_wu_splits.py`（事后补 SUBJECT_ID），已获取全文作为复用基础；两者依赖已被移除的 `mimic_comal` 与 `sparse` 包，需要改写。

## 实现步骤

1. **新增组装模块 `src/al_mimic/tasks/mimic_iii/preprocessing/build_splits.py`**
   - 两种模式（一个 CLI）：
     - **组装模式（默认）**：从 population.hdf5 + IDs.csv + notes.hdf5 + icustays_MV.csv + Xs.hdf5 组装新 splits.hdf5。行序断言（IDs.csv 与 population 顺序 `np.array_equal`）；notes 缺失行用 `scenarios.empty_note` 填充并标 `notes_available=False`；写 `with_notes/{train,val,test}`，每个 split 含 X、s、input_ids/token_type_ids/attention_mask、label、**subject_id**、careunit_code、notes_available，root 写 `careunit_codes`/`observation_hours` attrs；写完做跨 split subject 泄漏检查；输出已存在时拒绝覆盖。
     - **修补模式（`--attach-only`）**：对已有 splits.hdf5，用同一行序约定重建每 split 的期望 label 顺序并校验逐行相等，然后把缺失的 subject_id/careunit_code/notes_available 和 attrs 追加写入，label 不匹配则拒绝。用于快速修复本地现有 15GB 文件。
   - X/s 从 Xs.hdf5 按行 gather（分块写盘，复用历史 `--chunk-rows`），不依赖 sparse；若 Xs.hdf5 缺失则给出明确错误。CLI 参数与现有 `extract_notes.py`/`build_diagnoses_population.py` 风格一致（`--data-dir/--task/--duration/--timestep/--group/--chunk-rows/--compression/--output/--attach-only`）。
2. **导出**：在 `preprocessing/__init__.py` 导出组装函数（与 `read_notes` 并列）。
3. **单元测试 `tests/unit/tasks/mimic_iii/test_build_splits.py`**（不依赖真实数据，tmp_path 构造最小中间产物）：
   - 组装后 splits 结构与 audit 契约一致（组、形状、subject_id 为正、行数）；
   - 行序不匹配时拒绝；输出已存在时拒绝；
   - 修补模式对缺 subject_id 的文件补全；label 顺序不匹配时拒绝；已有正确数组时幂等；
   - 缺失 notes 行被填充且 notes_available=False。
4. **修复本地数据**（用新脚本，只读审计之外的写操作）：
   - 先跑 `--attach-only` 修补 `fiddle_processed/.../splits.hdf5`（补 subject_id 等，几秒钟完成，避免重写 15GB）；
   - 把正式路径 `dataset/processed/yang_wu_mimic/.../splits.hdf5` 的坏符号链接替换为指向修补后本地文件的符号链接；
   - 确认 ClinicalBERT checkpoint 存在，然后跑 `uv run al-mimic validate-data --task mimic_iii --config configs/experiments/mimic_iii/modis.yaml` 验证通过。
5. **文档更新**：`dataset/README.md` 的 MIMIC-III 段落补充组装/修补命令；`BASE_TASK_MIMIC_III_MULTIMODAL.md` 预处理说明补一句组装步骤。

## 不做的事

- 不改 `audit_split_hdf5`、loader、scenarios 或任何模型/方法代码；
- 不把组装塞进 `al-mimic prepare`（prepare 语义保持为"审计已存在 HDF5 + 写 manifest"）；
- 不重写 15GB 文件做全量重组（修补模式已等价，完整重组命令会提供但默认不执行）；
- 不删除 `fiddle_processed` 下的旧 splits.hdf5。
